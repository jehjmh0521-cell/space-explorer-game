단원 개관과 성취기준은 PDF 28쪽에서 확인했습니다. PDF 39쪽과 61쪽의 학생용 본문·도해도 화면으로 확인했습니다. PDF의 안내는 학습 자료로 참고했으며 사용자 요청을 대체하는 실행 지시로 취급하지 않았습니다.

## 학습 설계

- 달의 **관찰 가능한 변화와 반복**에 집중합니다. 공전에 의한 위상 원리를 이해해야만 미션을 통과하게 만들지 않았습니다.
- 행성의 질량, 실제 거리, 자전 속도, 대기 성분 같은 구체적 물리량은 필수 퀴즈에서 제외했습니다.
- 계절별 별자리 대신 이 단원에 나오는 **북극성 주변 별자리**를 중심으로 구현했습니다.
- 태양은 별이며 행성 목록에 포함하지 않습니다. 목성이 ‘태양계에서 가장 큰 천체’라고 오해하지 않도록 설명합니다.
- 천왕성·해왕성의 기체 겉부분과 내부 구성을 구별합니다. 게임에서는 기체 행성에 착륙하지 않습니다.
- 북두칠성은 큰곰자리의 일부이고 북극성은 작은곰자리에 있습니다. W자 카시오페이아자리를 포함합니다.
- 소행성 충돌·탐사 신호는 게임 장치입니다. 천체가 같은 평면에 정지해 있거나 실제 항해 시간이 게임과 같다는 뜻이 아닙니다.

## 참고 게임 대조

독도 원정대의 HTML 엔진 로딩 부분에서 `three@0.162.0`을 확인했습니다. 원격 응답은 TLS 검증을 유지한 HTTPS 요청으로 가져왔고, Chromium에서 시작 화면과 ‘바로 독도 탐사하기’ 화면을 실행해 확인했습니다.

새 게임에 반영한 요소: 전체 화면 3D 공간, 낮은 다각형 수의 장면 표현, 명조 제목과 금빛 포인트, 반투명 HUD, 항해→발견→관측→퀴즈→도감의 순환, 완료 임명장. Three.js 외에 원본 게임의 커스텀 지형·셰이더·로직·사진은 가져오지 않았습니다.

## 30분 복습 구성

사용자 요청에 맞춰 권장 약 30분의 복습 활동으로 구성했습니다. 11곳마다 서로 다른 개념을 확인하는 2문항(총 22문항), 달의 주요 모양 5개 관찰, 북쪽 별자리 3종 완성, 연구실 3종을 포함합니다. 권장 배분은 달 7분·태양과 행성 12분·별자리 6분·종합 연구 5분이며 강제 시간 제한이나 대기는 없습니다. 예상 시간이며 실제 학생의 플레이 시간을 측정하지는 않았습니다.
