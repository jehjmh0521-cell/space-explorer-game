# 별빛 항해 — 우주 탐사대

우주선을 직접 조종하며 태양계, 달, 별자리를 탐험하는 한국어 학습 게임입니다.

## 바로 실행
1. 이 저장소의 **Code → Download ZIP**을 선택합니다.
2. 압축을 풉니다.
3. **index.html**을 Chrome, Edge 또는 Safari에서 엽니다.

설치나 로그인, 서버, 외부 이미지, 외부 폰트가 필요 없습니다. 모바일에서는 정적 웹 호스팅에 올린 URL로 실행하세요. 브라우저가 로컬 파일의 저장 공간을 제한하면 저장 불가 안내가 표시됩니다.

## 구성
- Canvas 2D 기반 독립 구현: 방향키/WASD, 모바일 방향 버튼, 목적지 선택 자동 항해
- 태양 + 8개 행성 + 달 관측소 + 별자리 관측소, 총 11개 미션
- 지구 자전과 낮/밤 실험, 8가지 달 위상 조작, 계절별 별자리 연결, 북극성 찾기
- 관측 퀴즈와 오답 재도전, 행성 순서 복원 보너스 챌린지
- 소행성대 장애물, 탐사 자료 12개 수집, 경험치, 도감, 4단계 탐험가 배지
- 로컬 자동 저장, JSON 기록 내보내기, 확인 후 초기화
- 소리 기본 꺼짐, 키보드 조작, 터치 지원, 동작 줄이기 설정 지원

## 중요한 제작 범위
사용자가 제공한 참고 사이트:
https://dokdo-day-game.chaessam.workers.dev/

개발 실행 환경이 GitHub 저장소 접근 오류로 시작되지 않아 참고 사이트의 화면과 엔진을 확인하지 못했습니다. 따라서 해당 사이트를 재현하거나 같은 엔진을 사용했다고 주장하지 않으며, Canvas 2D를 사용하는 독자적인 탐험형 초안입니다.

첨부 자료: **초_과학4-2(이상원)_교사용교과서_1.pdf**
파일 첨부는 확인했으나 실행 환경 부재로 다운로드·본문 추출을 할 수 없었습니다. 교과서와의 단원, 쪽수, 성취기준 대조는 **미완료**입니다. 현재 콘텐츠는 일반적인 초등 과학 수준을 중심으로 구성했습니다. 교과서 원본과 발췌 내용은 저장소에 포함하지 않았습니다.

게임 안 **학습 안내 · 기록 관리**에서도 이 상태를 확인할 수 있습니다.

## 과학 모형의 한계
- 천체 크기, 거리, 위치, 속도는 실제 비율이 아닙니다.
- 거대 기체/얼음 행성에서는 착륙하지 않고 원격으로 관측합니다.
- 달의 밝은 부분은 태양빛을 반사하며 모양 변화는 일반적으로 지구 그림자 때문이 아닙니다.
- 달의 위상 주기는 약 29.5일입니다. 삭/보름 때마다 일식/월식이 발생하는 것은 아닙니다. 궤도 기울기와 일식/월식은 이 모형에서 생략했습니다.
- 위상은 북반구에서 보는 모습을 단순화했습니다. 계절별 별자리는 우리나라 저녁 하늘의 대표 예시이며 관측 시각과 위치에 따라 달라집니다.
- 별자리 점의 위치와 밝기는 도식이며 같은 별자리의 별이 실제로 모여 있거나 같은 거리에 있다는 뜻이 아닙니다.
- 별자리 게임에는 실제 하늘 방향과 축척을 정확히 재현하지 않은 모형이 사용됩니다.
- 태양을 맨눈이나 일반 망원경으로 직접 관찰해서는 안 됩니다.

## 웹 주소로 게시하기
현재는 소스 제작 단계이며 배포 완료를 의미하지 않습니다.
GitHub Pages를 사용하려면 저장소의 **Settings → Pages → Build and deployment**에서:
- Source: **Deploy from a branch**
- Branch: **main**, 폴더: **/(root)**
- **Save**

GitHub가 실제 게시 완료와 주소를 표시할 때 해당 주소를 사용하세요. 별도 백엔드 설정은 필요 없습니다.

## 검증
- Node.js 22 이상: \`node --test tests/core.test.cjs\`
- 브라우저: \`npm install --ignore-scripts\`, \`npx playwright install chromium\`, \`npx playwright test\`
- GitHub Actions의 **Game checks**가 코어 검증과 Chromium 데스크톱/모바일 흐름을 실행합니다.
- CI 성공 여부는 저장소의 Actions 결과를 확인하세요. 로컬 개발 환경은 사용할 수 없어 로컬 브라우저 QA는 수행하지 못했습니다.
