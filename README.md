# 우주 원정대 — 별빛 너머의 항해

초등 과학 4-2 「밤하늘 관찰」을 배우는 전체 화면 3D 우주 탐험 게임입니다. 이전 Canvas 2D 초안을 대체한 새 구현입니다.

[독도 원정대](https://dokdo-day-game.chaessam.workers.dev/)의 실제 페이지, 시작·탐사 화면 및 엔진 로딩 코드를 확인했습니다. 같은 **Three.js 0.162.0**을 사용하며, 전체 화면 3D 항해, 명조 제목, 금빛 버튼, 반투명 안내창, 발견 지점과 수집 도감의 흐름을 참고했습니다. 참고 사이트의 소스·사진·지형·브랜드를 복제하지 않고 우주 장면과 학습 코드를 새로 제작했습니다.

## 실행

Node.js **22.12 이상** 또는 **24 LTS**가 필요합니다.

```sh
npm ci
npm run dev
```

Vite가 포트 4173에서 실행됩니다. ES 모듈과 로컬 번들 자산을 사용하므로 HTML 파일을 직접 더블클릭하는 방식은 지원하지 않습니다. 로그인·API 키·데이터베이스는 필요하지 않습니다.

```sh
npm run build
npm run preview
```

`dist/`가 정적 배포 결과입니다. 상대 자산 경로를 사용하므로 하위 경로의 정적 호스팅도 지원합니다. Three.js와 한국어 폰트는 번들에 포함되며, 게임 실행 시 외부 CDN이나 폰트 서버를 호출하지 않습니다. 서비스워커 기반 오프라인 설치는 제공하지 않습니다.

## 권장 30분 복습 흐름

달 표면·모양 관찰 7분 → 태양과 여덟 행성 관측·확인 문제 12분 → 북쪽 별자리 세 가지와 북극성 6분 → 연구실 종합 복습 5분을 권장합니다. 읽기와 조작 속도에 따라 약 25~35분이며, 실제 학습자 대상 시간 측정 결과는 아닙니다. 강제 대기나 시간 제한 없이 자기 속도로 진행하고 완료한 천체의 기록을 이어갈 수 있습니다. 미완료 관측 활동과 퀴즈의 중간 단계는 저장하지 않습니다.

## 게임

- **3D 항해:** 우주선, 절차적으로 생성한 행성·고리·충돌 구덩이·소행성대·별 배경.
- **조작:** 방향키/WASD로 방향·높이 조절, Space 가속, E 관측. 터치 방향 버튼과 화면 끌기 지원.
- **탐험:** 직접 항해, 목적지 자동 항해, 바로 관측. 관측 장면에서는 화면을 끌어 천체를 돌려 봅니다.
- **11곳 관측:** 태양, 8개 행성, 달, 북쪽 별자리 관측소. 천체별 2문항, 총 22문항을 풀며 각 천체 첫 완료에 100 XP.
- **달 실험:** 표면 3곳 조사, 시간을 움직여 달 주요 모양 5개 관찰, 약 30일 주기 확인.
- **별자리:** 북두칠성·작은곰자리·카시오페이아자리 모두 잇기, 북극성과 북쪽 찾기.
- **연구실:** 행성 순서·표면 분류·상대적 크기 비교. 연구 배지 각 50 XP.
- **항해 도전:** 소행성 충돌과 기지 수리, 탐사 신호 8개 수집(각 10 XP). 자동 항해는 충돌 피해로부터 보호됩니다.
- **기록:** 브라우저 로컬 자동 저장, 도감 복습, JSON 내보내기, 확인 후 초기화.
- **완료:** 11곳 탐사 후 SVG 임명장 다운로드. 동일 활동을 반복해도 점수는 중복 지급하지 않습니다.

소리는 기본적으로 꺼져 있습니다. 시간 제한과 오답 감점은 없습니다. 저장 공간을 사용할 수 없으면 기록을 내려받도록 안내합니다. 이전 2D 초안의 저장 데이터와 별도의 키를 사용합니다.

## 교과서 연결

첨부 PDF의 이미지 페이지를 직접 확인하고 한국어 OCR로 대조했습니다. 원본 교과서 이미지나 OCR 전문은 저장소·배포물에 포함하지 않았습니다. [학습 내용 대응표](docs/curriculum.md)에 학생용 쪽수, PDF 쪽수와 성취기준을 정리했습니다.

학습 내용은 학생에게 맞게 새로 작성했습니다. 필수 퀴즈는 달 표면·모양의 반복, 행성의 관찰 가능한 특징, 별의 정의, 북극성 주변 별자리에 집중합니다.

## 모형의 범위

- 크기·거리·위치·속도·행성 공전 경로는 실제 비율이 아닌 게임 배치입니다. 실제 천문 관측 예보가 아닙니다.
- 달 시간 이동은 약 30일 주기의 간략한 모형이며 실제 평균 주기는 약 29.5일입니다. 같은 시각에 모든 달 모양을 볼 수 있는 것은 아닙니다.
- 달의 실제 모양은 둥근 공입니다. 공전에 의한 위상 변화 원리는 이 학년의 필수 평가에 넣지 않았습니다.
- 기체 행성에서는 우주선으로 관측하며 착륙하지 않습니다. 교과서의 ‘기체 표면’은 보이는 겉부분을 뜻하고 내부 전체가 기체라는 뜻은 아닙니다.
- 별자리 모형은 위치·밝기를 단순화했습니다. 별자리를 이루는 별들이 실제로 가까이 모여 있다는 뜻은 아닙니다.
- 태양을 맨눈이나 일반 망원경으로 직접 관측하지 않습니다. 실제 야간 관측은 어른과 함께합니다.

## 검증

```sh
npm test
npm run test:browser
npm run build
```

Playwright는 시스템의 `/usr/bin/chromium`이 있으면 사용합니다. 다른 위치는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`로 지정합니다. 브라우저가 없다면 `npx playwright install --with-deps chromium`으로 설치합니다. 클라우드에서 npm 캐시 권한 문제가 있으면 `npm ci --cache /workspace/.cache/npm`을 사용합니다.

데스크톱 Chromium과 Pixel 7 크기·터치 에뮬레이션으로 실제 화면, 자동 항해, 관측 잠금, 오답 재도전, 저장·복습, 연구 배지, 11곳 완료와 임명장 다운로드를 검사합니다. 실제 iOS/Safari 기기의 GPU 성능까지 검증한 것은 아닙니다. WebGL을 사용할 수 없을 때는 원인과 재시도 안내를 표시합니다.

번들에 포함된 Three.js 및 폰트의 라이선스는 `public/licenses/`에 보존하며, 빌드 시 `dist/licenses/`로 복사됩니다.

## GitHub Pages 배포

`.github/workflows/deploy-pages.yml`은 `main` 갱신 또는 수동 실행 시 의존성 설치·학습 로직 검증·프로덕션 빌드를 거쳐 `dist/`를 GitHub Pages에 게시합니다. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정해야 합니다. 소스 브랜치의 개발용 index.html을 그대로 게시하지 않습니다.

배포 결과와 실제 주소는 Actions의 **Deploy game to GitHub Pages** 실행 결과에서 확인합니다. 배포 성공 전에는 예상 주소를 완료된 사이트로 안내하지 않습니다.
